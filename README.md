# ❄️ Frostpremium

Telegram uchun yaratilgan **FrostShop** bot — Telegram Stars va Premium xizmatlarini boshqarish va buyurtmalarni qabul qilish uchun mo‘ljallangan.

## ✨ Imkoniyatlar

* ⭐ Telegram Stars paketlari
* 💎 Telegram Premium
* 🔐 Akkount uchun Premium buyurtmasi
* 🎁 Premium Gift buyurtmalari
* 📦 Buyurtmalar tarixi
* 📢 Majburiy kanalga obuna tekshiruvi
* 👥 Foydalanuvchilar statistikasi
* 👑 Admin panel
* 💰 Mahsulot narxlarini admin orqali o‘zgartirish
* 📊 Buyurtmalarni boshqarish
* 🔔 Yangi buyurtmalar haqida admin xabarnomalari

## 🛠 Texnologiyalar

* Python
* python-telegram-bot
* SQLite
* Telegram Bot API

## ⚙️ O‘rnatish

Kerakli kutubxonalarni o‘rnating:

```bash
pip install -r requirements.txt
```

Bot tokenini xavfsiz environment variable orqali kiriting:

```bash
set BOT_TOKEN=YOUR_BOT_TOKEN
```

Botni ishga tushiring:

```bash
python frostt.py
```

## 🔐 Xavfsizlik

Bot tokeni, parollar va boshqa maxfiy ma'lumotlarni GitHub repository'ga joylamang.

Environment Variables yoki Secrets orqali saqlang.

## 👨‍💻 Admin

Admin funksiyalari faqat `ADMIN_IDS` ichidagi Telegram ID'larga ochiq.

## 📞 Yordam

Bot orqali buyurtma yoki xizmat bo‘yicha yordam olish mumkin.
